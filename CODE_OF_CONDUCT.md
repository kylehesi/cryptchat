# Code of Conduct

CryptChat follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

## In short

- Be respectful and constructive. Critique code and ideas, not people.
- No harassment, insults, discrimination, or sexualized language or imagery.
- Do not publish other people's private information without their permission.
- Assume good faith, and help newcomers.

## Scope

This applies to all project spaces (issues, pull requests, discussions) and to anyone
representing the project elsewhere.

## Enforcement

Report unacceptable behavior to the maintainer through GitHub
([@kylehesi](https://github.com/kylehesi)). Reports are handled confidentially. The maintainer
may remove comments, close threads, or block participants who break these rules.
